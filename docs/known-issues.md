# Known issues

Problems that are understood but not resolved. Each entry says what is wrong,
what the evidence is, and what would close it.

## S15E02 is a James Lipton special, not the Dave Chappelle episode

Status: open, tracked in `itas/audit.py` under `KNOWN_ISSUES`.

Wikipedia lists season 15, episode 2 as *Dave Chappelle*, aired 10 November
2008. The archive holds:

```text
Season 15/S15E02.JamesLipton-2008.11.10.ITAS.SD.mp4   (703 MB)
```

The air date matches. The guest does not. The changelog entry from 23 May 2026
describes the addition as "Dave Chappelle's episode 02 (James Lipton
celebration)", which reads like a tribute special that aired in the same slot
rather than a Chappelle interview.

To close: watch the first two minutes. If it is a Lipton tribute, move it to
`Season 00` as a special and cross S15E02 as missing. If it is a mislabelled
Chappelle interview, rename the file.

The audit reports this as `INFO` rather than `ERROR` so CI stays green.
`tests/test_repository.py::test_only_the_known_s15e02_mismatch_remains` pins
it, so a second mismatch cannot slip in unnoticed.

## Legacy filenames that predate the naming convention

Status: accepted, documented in `itas/naming.py` under `LEGACY_EXCEPTIONS`.

33 video files do not follow `S{SS}E{EE}.{Guest}-{YYYY.MM.DD}.ITAS.{SD|HD}.mp4`:

| Kind | Count | Example |
| --- | --- | --- |
| AVI/MKV originals | 15 | `S08E01.BenStiller-2001.09.30.ITAS.SD.avi` |
| Season 0 extras | 11 | `S00E04.RobertDeNiro.DeletedScenes#1.ITAS.SD.mp4` |
| Doubled extension | 2 | `S11E02.JamesGandolfini-2004.10.17.ITAS.SD.mp4.mp4` |
| Markers in the wrong place | 5 | `S12E03.QueenLatifah(RussianDub)-2006.01.08.ITAS.SD.mp4` |

Renaming them would break every existing Drive share link, so they are
exempted by name with a documented reason. `itas verify-names` fails if a file
is not canonical and not exempt, and reports any exemption that no longer
matches a real file, so the list cannot rot.

To close: re-encode the AVI and MKV files to MP4, rename them in Drive during
a release, and delete the matching entries from `LEGACY_EXCEPTIONS`.

## The tracking post and the README both carry the checklist

Status: open.

`available-global.txt` is the master Reddit and DHExchange post. `README.md`
carries the same checklist. Both are now generated by
`itas render --write --also README.md`, so they cannot drift, but the content
is duplicated.

To close: decide which one is canonical. The post is what people read, so the
README could link to it instead of repeating it.
